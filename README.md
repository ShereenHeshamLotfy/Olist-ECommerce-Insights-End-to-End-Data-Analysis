# 🛒 Olist E-Commerce Analytics – End-to-End Business Intelligence Case Study

This project analyzes a real-world Brazilian e-commerce dataset to uncover insights across **sales performance, customer behavior, delivery efficiency, and product performance**.

It simulates a complete **end-to-end data analytics workflow**, transforming raw data into actionable business insights using SQL and Power BI.

---

## 💼 Key Highlights

- Analyzed **~100K orders** and **~99K customers** generating **16M total revenue insights**
- Built a full **interactive Power BI dashboard** covering 6 key business domains
- Achieved **95.9% on-time delivery analysis** with detailed delay investigation
- Identified key drivers of **customer behavior, revenue growth, and satisfaction**

---

## 🚀 Project Overview

The project follows a structured analytics pipeline:

- **SQL** → Data cleaning, transformation, and preparation  
- **Star Schema** → Optimized data model for efficient analysis  
- **Power BI** → Interactive dashboards and business storytelling  

The dataset includes **~100K orders, 99K customers, and multiple related tables**, simulating a real-world business intelligence scenario.

---

## 👩‍💻 My Role

- Designed and implemented a **Star Schema data model**
- Cleaned and transformed raw data using **SQL**
